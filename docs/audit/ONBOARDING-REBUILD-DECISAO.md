# DECISÃO — REBUILD GREENFIELD DO ONBOARDING

A partir de 2026-09-07, o onboarding existente é considerado legado congelado.

## Decisão irrevogável durante o rebuild

Não serão feitos remendos estruturais no onboarding legado com o objetivo de transformá-lo no novo onboarding.

Nenhuma página, arquivo, componente, hook ou serviço do legado será aproveitado integralmente como implementação do novo fluxo.

O novo onboarding será escrito novamente, linha por linha.

## Motivo

O onboarding acumulou alterações e responsabilidades históricas suficientes para que a reutilização de sua estrutura de código carregue dívida, contratos divergentes, estados duplicados e comportamentos acidentais para a nova implementação.

O custo de reconstrução é aceito para reduzir o risco de perpetuar esse ciclo.

## O que pode atravessar a fronteira

Somente conhecimento validado:

- requisitos reais do produto;
- regras de domínio confirmadas;
- necessidades legais/comerciais;
- decisões de UX que continuem fazendo sentido.

A implementação antiga não atravessa a fronteira.

## Regra operacional

Quando houver dúvida entre reutilizar e reescrever, reescrever.
