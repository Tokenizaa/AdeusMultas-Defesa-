# Adeus Multa — Sistema Editorial

**Resumo:** Sistema editorial oficial do Adeus Multa. Garante que toda comunicação da marca seja educativa, simples, acessível, objetiva, tecnicamente precisa e juridicamente responsável.

**Responsabilidade Única:** Esta skill é a única fonte de verdade para produção de conteúdo de marketing do Adeus Multa. Substitui skills genéricas (copywriting, social, content-strategy) para o contexto específico da plataforma. Se o conteúdo não for sobre Adeus Multa, multas de trânsito ou defesa administrativa, outra skill é mais adequada.

## Antes de Produzir Conteúdo

Leia os arquivos de referência na ordem abaixo. Cada arquivo tem responsabilidade única e fornece contexto essencial.

### 1. Posicionamento da Marca

**Arquivo:** `references/positioning.md`

Leia este arquivo primeiro. Ele define:

- Missão, visão e proposta de valor
- Diferenciais competitivos
- O que a plataforma NÃO é (não é escritório de advocacia, não é despachante)
- Branding e promessa da marca

### 2. Personas

**Arquivo:** `references/personas.md`

Leia para entender:

- Perfis de público-alvo
- Dores, desejos e objeções de cada persona
- Linguagem adequada para cada perfil
- Canais preferenciais

### 3. Pilares Editoriais

**Arquivo:** `references/editorial-pillars.md`

Define os 5 pilares de conteúdo. Todo conteúdo deve se encaixar em pelo menos um pilar.

### 4. Framework de Conteúdo

**Arquivo:** `references/content-framework.md`

Framework oficial para cada formato:

- Reels
- Carrosséis
- Stories
- Posts
- Artigos e blog

### 5. Proibições Legais

**Arquivo:** `references/prohibited-claims.md`

LEIA OBRIGATORIAMENTE antes de finalizar qualquer conteúdo. Contém restrições legais que nunca podem ser violadas.

## Fluxo de Criação de Conteúdo

Sempre siga estas etapas nesta ordem:

### Etapa 1: Briefing

Identifique:

- **Formato:** Reel, Carrossel, Story, Post, Artigo, Campanha
- **Objetivo:** Educação, autoridade, engajamento, lead, venda
- **Pilar editorial:** Qual pilar este conteúdo serve
- **Persona:** Para quem estamos falando
- **CTA desejado:** Qual ação queremos que o usuário tome

### Etapa 2: Consulta às Referências

Com base no formato e objetivo, leia os arquivos relevantes:

| Formato         | Arquivos                                               |
| --------------- | ------------------------------------------------------ |
| Reels           | `references/reels.md`, `references/cta-library.md`, `references/visual-identity.md`     |
| Carrosséis      | `references/carousels.md`, `references/cta-library.md`, `references/visual-identity.md` |
| Stories         | `references/stories.md`, `references/cta-library.md`                         |

| Calendário      | `references/content-calendar.md`, `references/planning-policy.md`, `references/editorial-pillars.md` |
| CTA / Ação      | `references/cta-library.md`, `references/cta-matrix-by-action.md`           |
| Autonomia       | `references/autonomy-guardrails.md` (obrigatório no modo autonomia total)   |

### Etapa 3: Criação

Produza o conteúdo seguindo:

1. O framework específico do formato (em `references/content-framework.md`)
2. O tom e identidade visual (em `references/visual-identity.md`)
3. A biblioteca de CTAs (em `references/cta-library.md`)
4. As diretrizes de SEO (em `references/seo.md`, quando aplicável)

### Etapa 4: Refinamento de Conteúdo

Antes de entregar, execute o checklist de `references/content-checklist.md`:

- [ ] Fonte oficial citada quando aplicável?
- [ ] Linguagem simples e acessível?
- [ ] CTA presente e alinhado ao objetivo?
- [ ] Informação tecnicamente precisa?
- [ ] Pode gerar interpretação errada? (se sim, revise)
- [ ] Viola alguma proibição de `references/prohibited-claims.md`?
- [ ] Alinhado ao pilar editorial correto?
- [ ] Tom consistente com a identidade visual?
- [ ] No modo autonomia total: `legal_status` = `approved` (ver `references/autonomy-guardrails.md`)?

### Etapa 5: Refinamento

Ajuste conforme necessário com base no checklist. Se o conteúdo for para múltiplos canais, adapte o formato para cada um seguindo as diretrizes específicas.

## Tom e Voz

### Regras de Ouro

1. **Educativo, não técnico-jurídico.** Explique conceitos de forma simples. Nunca pareça um escritório de advocacia.
2. **Acessível, não simplório.** Respeite a inteligência do leitor, mas use linguagem clara.
3. **Confiável, não sensacionalista.** Baseie afirmações em fontes oficiais (CTB, resoluções CONTRAN, jurisprudência).
4. **Direto, não prolixo.** Vá direto ao ponto. Corte rodeios.
5. **Humano, não institucional.** Fale como uma pessoa que entende do assunto, não como um robô corporativo.

### Percepção Desejada

O Adeus Multa deve ser percebido como:

> "O especialista digital em defesa administrativa de trânsito."

Alguém que:

- Conhece profundamente a legislação de trânsito brasileira
- Explica de forma clara o que está acontecendo
- Não promete resultados, mas mostra o caminho
- Gera confiança pela precisão técnica, não por promessas
