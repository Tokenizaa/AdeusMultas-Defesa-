# Exemplo de Sequência de Stories — Educativa

## Tema: Diferença entre Defesa Prévia e Recurso JARI

### Story 1: Gancho + Interação

```
Background: Gradiente azul (#1351B4 → #0B3A8C)

Texto central (grande):
VOCÊ SABE A
DIFERENÇA ENTRE...

...DEFESA PRÉVIA
E RECURSO JARI?

[Caixa de resposta no topo]
Enquete: "Sabia a diferença?"
Opções: "Sim" / "Não"

Ponto de cor azul claro pulsando indicando enquete.
```

### Story 2: Defesa Prévia

```
Background: Branco (#FFFFFF)

Texto central (bold, azul escuro):
DEFESA PRÉVIA

Texto inferior (regular, 30px):
É a PRIMEIRA oportunidade
de contestar a multa.

Você apresenta seus argumentos
antes da autoridade julgar.

Dica: geralmente 30 dias
da notificação.

Ícone: Documento com seta (canto superior direito)
```

### Story 3: Recurso JARI

```
Background: Branco (#FFFFFF)

Texto central (bold, azul escuro):
RECURSO JARI

Texto inferior (regular, 30px):
É a SEGUNDA instância.

Você recorre quando a
defesa prévia foi indeferida.

A JARI reavalia o caso
com novo julgamento.

Ícone: Documento com balança (canto superior direito)
```

### Story 4: Comparação + Quiz

```
Background: Azul claro (#E8F0FE)

Texto:
QUAL A PRINCIPAL
DIFERENÇA?

1️⃣ Defesa Prévia: ANTES da decisão
2️⃣ Recurso JARI: APÓS a decisão

[Quiz sticker ou caixa de pergunta]
"Qual você já fez ou faria?"
Caixa de resposta aberta
```

### Story 5: CTA

```
Background: Gradiente azul (#0B3A8C)

Logo Adeus Multa centralizado (pequeno, no topo)

Texto central (branco, bold):
TEM UMA MULTA
PRA RESOLVER?

CTA (destaque verde):
FAÇA SUA ANÁLISE
GRÁTIS

[Sticker de link se disponível, ou seta apontando para link na bio]

Ícone swipe up no final
```
