# Checklist de Conteúdo — Adeus Multa

## Uso Obrigatório

Este checklist deve ser executado antes da publicação de TODO conteúdo.

Marque cada item como [OK] ou [REVISAR]. Se houver "REVISAR", corrija antes de publicar.

---

## Checklist Universal

### Precisão Técnica

- [ ] Fonte oficial citada (CTB, resolução CONTRAN, jurisprudência)?
- [ ] Número do artigo ou resolução correto?
- [ ] Informação está atualizada (CTB vigente, resoluções mais recentes)?
- [ ] Prazo mencionado está correto (dias corridos x úteis)?
- [ ] Dados estatísticos têm fonte verificável?

### Clareza e Linguagem

- [ ] Linguagem simples e acessível para leigo?
- [ ] Termos jurídicos explicados quando inevitáveis?
- [ ] Frases curtas e objetivas (máximo 20 palavras)?
- [ ] Parágrafos curtos (máximo 3 linhas)?
- [ ] Um conceito por vez?

### Conformidade Legal

- [ ] Nenhuma promessa de resultado (ganho, anulação, cancelamento)?
- [ ] Nenhum termo proibido (ver `prohibited-claims.md`)?
- [ ] Nada que possa ser interpretado como propaganda enganosa?
- [ ] Disclaimer presente quando necessário?
- [ ] `legal_status` = `approved` pelo legal-sync (obrigatório no modo autonomia total, ver `autonomy-guardrails.md`)?

### CTA e Conversão

- [ ] CTA presente e alinhado ao objetivo do conteúdo?
- [ ] CTA específico (não genérico como "clique aqui")?
- [ ] CTA de baixo compromisso para topo de funil?
- [ ] Ação desejada clara para o leitor?

### Marca e Consistência

- [ ] Tom consistente com a identidade da marca?
- [ ] Cores e elementos visuais seguem identidade?
- [ ] Logo Adeus Multa presente (quando aplicável)?
- [ ] Link para plataforma ou bio incluído?

### Segurança e Ética

- [ ] Pode gerar interpretação errada no leitor?
- [ ] Alguém pode agir com base apenas neste conteúdo sem buscar orientação?
- [ ] Conteúdo expõe a plataforma a risco legal?
- [ ] Dados de terceiros anonimizados adequadamente?

## Checklist por Formato

### Reels

- [ ] Gancho nos primeiros 2 segundos?
- [ ] Legendas grandes e legíveis?
- [ ] Um único conceito abordado?
- [ ] Duração entre 30-60 segundos?
- [ ] CTA verbal + textual?
- [ ] Música não abafa a voz?
- [ ] Capa (thumbnail) personalizada?

### Carrosséis

- [ ] Máximo 10 slides?
- [ ] Texto máximo de 3 linhas por slide?
- [ ] Elemento visual em pelo menos 50% dos slides?
- [ ] Último slide com CTA claro?
- [ ] Fonte legível em mobile (mín 30px títulos)?
- [ ] Slide 1 (capa) para de scroll?

### Stories

- [ ] Máximo 7 stories por sequência?
- [ ] Texto grande (30-50% da tela)?
- [ ] Elemento interativo a cada 2-3 stories?
- [ ] Fundo limpo (sem poluição visual)?
- [ ] CTA presente quando aplicável?
- [ ] Stories educativos salvos em Destaques?

### Posts Estáticos

- [ ] Primeira linha funciona como gancho?
- [ ] Máximo 5 parágrafos?
- [ ] Parágrafos de 1-3 linhas?
- [ ] Emojis com moderação (1-2 por post)?
- [ ] Link na bio ou story mencionado?

### Artigos / Blog

- [ ] Título otimizado para SEO (palavra-chave + gancho)?
- [ ] Meta description preenchida?
- [ ] Subtítulos (H2, H3) organizados?
- [ ] Links para fontes oficiais funcionando?
- [ ] Imagens com alt text descritivo?
- [ ] CTA no final do artigo?
- [ ] CTA contextual ao longo do texto?
- [ ] Entre 800-2000 palavras?
- [ ] URLs amigáveis?

---

## Checklist de Campanhas

- [ ] Alinhada aos pilares editoriais?
- [ ] Público-alvo definido?
- [ ] Objetivo claro (awareness, consideração, conversão)?
- [ ] Métricas de sucesso definidas?
- [ ] Orçamento e recursos alocados?
- [ ] Cronograma definido?
- [ ] Peças adaptadas para cada canal?
- [ ] CTA consistente em todos os canais?
- [ ] Teste A/B planejado (quando aplicável)?
- [ ] Pós-campanha: análise de resultados?

---

## Checklist de Responsividade (Multiplataforma)

- [ ] Conteúdo funciona no mobile (onde será mais consumido)?
- [ ] Texto legível sem zoom?
- [ ] Imagens carregam rapidamente?
- [ ] Links e CTAs funcionam em app?
- [ ] Formato adaptado para a plataforma de publicação?
