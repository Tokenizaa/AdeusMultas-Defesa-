# Biblioteca de CTAs — Adeus Multa

## Como Usar

Cada CTA é categorizado por objetivo. Consulte esta biblioteca sempre que precisar definir a chamada para ação de um conteúdo.

## Categoria: Autoridade

**Objetivo:** Posicionar a plataforma como referência e construir credibilidade.

| CTA                            | Contexto                              |
| ------------------------------ | ------------------------------------- |
| "Saiba como funciona"          | Conteúdos educativos sobre o processo |
| "Entenda seus direitos"        | Conteúdos sobre direitos do motorista |
| "Veja a análise completa"      | Conteúdos sobre legislação            |
| "Acesse o guia completo"       | Posts que resumem guias maiores       |
| "Descubra se você tem direito" | Conteúdos sobre situações específicas |

**Tom:** Confiante, informativo, sem pressão

---

## Categoria: Engajamento

**Objetivo:** Gerar interação e conversa com o público.

| CTA                                         | Contexto                                     |
| ------------------------------------------- | -------------------------------------------- |
| "Já passou por isso? Conta nos comentários" | Conteúdos de identificação                   |
| "Salva pra ver depois"                      | Conteúdos educativos (incentivar salvamento) |
| "Compartilha com quem precisa saber"        | Conteúdos de utilidade pública               |
| "Qual sua maior dúvida? Manda aí"           | Conteúdos abertos a perguntas                |
| "Responde o quiz nos stories"               | Conteúdos de interação                       |
| "Me marca nos stories se fizer"             | Conteúdos acionáveis                         |
| "Você sabia? Deixa sua reação"              | Conteúdos de curiosidade                     |

**Tom:** Conversacional, próximo, convidativo

---

## Categoria: Compartilhamento

**Objetivo:** Incentivar o usuário a compartilhar o conteúdo.

| CTA                                            | Contexto                       |
| ---------------------------------------------- | ------------------------------ |
| "Marque aquele amigo que precisa ver isso"     | Conteúdos educativos e alertas |
| "Envia pro grupo da família"                   | Conteúdos de utilidade pública |
| "Salva e compartilha"                          | Carrosséis educativos          |
| "Se conhece alguém que passou por isso, marca" | Conteúdos de identificação     |

**Tom:** Colaborativo, útil, social

---

## Categoria: Leads (Captura)

**Objetivo:** Levar o usuário a se cadastrar ou fornecer contato.

| CTA                                              | Contexto                                 |
| ------------------------------------------------ | ---------------------------------------- |
| "Faça sua análise gratuita"                      | Principal CTA de conversão               |
| "Analise sua multa grátis"                       | Posts sobre análise                      |
| "Teste grátis por [período]"                     | Conteúdos de produto                     |
| "Cadastre-se e veja se vale a pena recorrer"     | Posts educativos sobre casos específicos |
| "Receba o guia completo no seu email"            | Posts de isca digital                    |
| "Quer saber se sua multa tem jeito? Comece aqui" | Conteúdos de dor                         |

**Tom:** Convidativo, de baixo compromisso, transparente

---

## Categoria: Venda Direta

**Objetivo:** Conversão imediata para plano pago.

| CTA                                | Contexto                        |
| ---------------------------------- | ------------------------------- |
| "Comece agora"                     | Calls to action gerais de venda |
| "Assine o plano ideal para você"   | Conteúdos de planos             |
| "Garanta sua defesa"               | Conteúdos de urgência (prazo)   |
| "Quero resolver minha multa agora" | Conteúdos de ação imediata      |
| "Ver planos e preços"              | Conteúdos de precificação       |

**Tom:** Direto, claro, sem pressão, mas com senso de oportunidade

---

## Categoria: Lista de Espera

**Objetivo:** Capturar interesse para lançamentos futuros.

| CTA                          | Contexto               |
| ---------------------------- | ---------------------- |
| "Entre na lista de espera"   | Pré-lançamento         |
| "Seja avisado quando lançar" | Novas funcionalidades  |
| "Garanta sua vaga"           | Webinars, eventos      |
| "Ative o lembrete"           | Conteúdos sobre prazos |

**Tom:** Exclusivo, antecipatório

---

## Categoria: Provas Sociais

**Objetivo:** Converter através de exemplos e depoimentos.

| CTA                                       | Contexto                    |
| ----------------------------------------- | --------------------------- |
| "Veja como ajudamos [perfil]"             | Depoimentos                 |
| "Cada caso é único — veja como ajudamos"  | Casos de sucesso (anônimos) |
| "Mais de X defesas geradas. Comece a sua" | Métricas                    |
| "Veja o depoimento completo"              | Conteúdos de terceiros      |

**Tom:** Aspiracional, mas realista

## Matriz CTA x Formato

| Formato           | CTAs Recomendados                                       |
| ----------------- | ------------------------------------------------------- |
| Reel educativo    | "Salva pra ver depois" + "Link na bio"                  |
| Reel mito/verdade | "Compartilha com quem também acha isso"                 |
| Carrossel         | "Salva e compartilha" (meio) + "Faça sua análise" (fim) |
| Story engajamento | Enquete + "Responde aí"                                 |
| Story lead        | "Link na bio" ou sticker de link                        |
| Post educativo    | "Salva pra consultar depois" + "Link na bio"            |
| Post produto      | "Teste grátis" + "Link na bio"                          |
| Artigo blog       | CTA in-text + CTA final "Comece agora"                  |

## Regras para CTAs

- Um CTA principal por conteúdo (se tiver mais, hierarquizar)
- CTA deve ser específico: "Faça sua análise gratuita" > "Clique aqui"
- Tom de CTA consistente com o tom do conteúdo
- CTA não deve prometer o que não pode entregar
- Em conteúdo de topo de funil, preferir CTA de baixo compromisso
- Em conteúdo de fundo de funil, CTA direto para conversão
