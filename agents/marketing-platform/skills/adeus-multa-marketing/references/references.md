# Referências — Adeus Multa

## Legislação Oficial

### Código de Trânsito Brasileiro (CTB)

**Lei nº 9.503, de 23 de setembro de 1997**

- Fonte oficial: https://www.planalto.gov.br/ccivil_03/leis/l9503compilado.htm
- Documento base de toda a legislação de trânsito brasileira
- Artigos mais relevantes para defesas: Arts. 128 a 286 (Processo Administrativo)

### Resoluções CONTRAN

- Resolução CONTRAN nº 619/2016 — Procedimentos para imposição de multas
- Resolução CONTRAN nº 985/2022 — Atualização de valores de multas
- Resolução CONTRAN nº 882/2021 — Suspensão do direito de dirigir
- Consultar sempre a versão mais atualizada em: https://www.gov.br/infraestrutura/pt-br/assuntos/transito/conteudo-contran/resolucoes

### Legislação Complementar

- Lei nº 12.403/2011 — Medidas cautelares (inclui CNH)
- Lei nº 13.281/2016 — Alterações no CTB (multas, pontos)
- Lei nº 14.071/2020 — Alterações no CTB (atualização geral)

## Glossário Adeus Multa

### Termos de Trânsito

| Termo            | Significado Simples                                                           |
| ---------------- | ----------------------------------------------------------------------------- |
| CTB              | Código de Trânsito Brasileiro — a lei que regula o trânsito                   |
| CONTRAN          | Conselho Nacional de Trânsito — define as regras                              |
| JARI             | Junta Administrativa de Recursos de Infrações — primeira instância do recurso |
| CETRAN           | Conselho Estadual de Trânsito — segunda instância                             |
| Defesa Prévia    | Primeira oportunidade de contestar a multa                                    |
| Recurso          | Pedido de revisão da decisão                                                  |
| Notificação      | Comunicado oficial sobre a infração                                           |
| Auto de Infração | Documento que registra a infração                                             |

### Termos da Plataforma

| Termo            | Significado                                          |
| ---------------- | ---------------------------------------------------- |
| Análise Técnica  | Avaliação da IA sobre os fundamentos da multa        |
| Documento Gerado | Defesa ou recurso produzido pela IA                  |
| Revisão Opcional | Etapa opcional onde o usuário pode conferir o documento |
| OCR              | Tecnologia que extrai texto de imagens e PDFs        |
