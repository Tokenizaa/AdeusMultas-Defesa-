# Frameworks de Conteúdo Adeus Multa

## Framework Universal

Todo conteúdo do Adeus Multa segue esta estrutura básica:

```
Gancho
↓
Problema
↓
Explicação
↓
Exemplo
↓
CTA
```

### 1. Gancho

Prende a atenção. Deve ser específico, relevante e direto.

**Fórmulas de gancho:**

- Pergunta: "Recebeu uma multa e não sabe o que fazer?"
- Dado: "80% das multas têm erro na notificação"
- Afirmação: "Suspensão da CNH não é o fim da linha"
- Contraste: "Todo mundo diz X, mas a verdade é Y"

### 2. Problema

Contextualiza a dor. Mostra que você entende a situação.

### 3. Explicação

Apresenta a informação ou solução. Deve ser clara, referenciada e objetiva.

### 4. Exemplo

Concretiza a explicação. Use exemplos reais (anônimos) ou situações comuns.

### 5. CTA

Direciona para a ação desejada. Consulte `cta-library.md`.

## Framework para Reels

**Estrutura resumida:** `reels.md`

**Regras principais:**

- Gancho nos primeiros 2 segundos
- Legendas grandes e visíveis
- Tom de conversa, não de palestra
- Um conceito por Reel
- Duração: 30-60 segundos

**Tipos de Reel:**

- **Educativo:** Explica um conceito (ex: "O que é JARI?")
- **Mito ou Verdade:** Desmistifica crenças comuns
- **Alerta:** Avisa sobre prazos ou mudanças
- **Pergunta & Resposta:** Responde dúvidas frequentes

---

## Framework para Carrosséis

**Estrutura resumida:** `carousels.md`

**Regras principais:**

- 5-10 slides
- Um ponto por slide
- Texto máximo 3 linhas por slide
- Elemento visual em pelo menos 50% dos slides
- Último slide sempre com CTA claro

**Tipos de Carrossel:**

- **Passo a Passo:** "Como recorrer de multa em 5 passos"
- **Lista:** "5 direitos que todo motorista tem"
- **Explicativo:** "O que significa cada artigo da multa"
- **Comparativo:** "Adeus Multa vs fazer sozinho vs advogado"

## Framework para Stories

**Estrutura resumida:** `stories.md`

**Regras principais:**

- Máximo 7 stories por sequência
- Incluir elemento interativo a cada 2-3 stories
- Texto grande (ocupar 30-50% da tela)
- Fundo limpo, sem poluição visual

**Tipos de Story:**

- **Bastidores:** Mostra o time ou o processo
- **Educativo rápido:** Uma dica em 5 segundos
- **Enquete:** Engaja e coleta dados
- **FAQ:** Responde perguntas frequentes
- **Prova social:** Print de depoimento ou resultado
- **Lançamento:** Anuncia novidades

## Framework para Posts Estáticos

### Estrutura

```
Título: Gancho em forma de headline
↓
Corpo: Explicação em parágrafos curtos (2-4 parágrafos)
↓
Call to Action: Frase final com ação clara
```

**Regras:**

- Máximo 5 parágrafos
- Parágrafos de 1-3 linhas
- Espaço entre parágrafos
- Emojis com moderação (1-2 por post)
- Link na bio ou story

## Framework para Artigos / Blog

**Detalhes completos em:** `seo.md`

### Estrutura

```
Título SEO: Palavra-chave + gancho
↓
Introdução: Contexto + o que será abordado
↓
Subtítulo H2: Primeiro ponto principal
    ↓
    Texto: Explicação + dados + fontes
Subtítulo H2: Segundo ponto principal
    ↓
    Texto: Explicação + dados + fontes
Subtítulo H2: Terceiro ponto principal
    ↓
    Texto: Explicação + dados + fontes
↓
Conclusão: Resumo + CTA
↓
FAQ: 3-5 perguntas frequentes com respostas curtas
```

**Regras:**

- Entre 800-2000 palavras
- Um H2 para cada conceito principal
- Links para fontes oficiais
- Imagens ou infográficos a cada 300 palavras
- Meta description e tags SEO
- CTA no final + CTA contextual ao longo do texto

## Framework para Landing Pages

### Estrutura

```
Hero: Headline + subheadline + CTA
↓
Problema: Contexto da dor
↓
Solução: Como o Adeus Multa resolve
↓
Benefícios: 3-5 diferenciais (com ícones)
↓
Como funciona: 3 passos simples
↓
Prova social: Números, depoimentos
↓
Preços: Planos e comparação (se aplicável)
↓
FAQ: Dúvidas frequentes
↓
CTA final: Último chamado para ação
```

## Framework para Legendas de Instagram

### Estrutura

```
[Linha 1-2] Gancho — frase que prende a atenção
[Linha 3-5] Contexto ou problema
[Linha 5-8] Explicação principal
[Linha 8-10] Exemplo ou dica
[Linha 10-12] CTA + link na bio

---
8-15 hashtags relevantes
```

**Regras:**

- Máximo 8 linhas de texto (o resto vai em "mais")
- Primeira linha é a mais importante (aparece no feed)
- Quebras de linha a cada 2-3 sentenças
- Hashtags: 8-15 por post, variar sempre
- Marcar perfil @adeusmulta (sugerido) ao final (não no início)
