# Diretrizes para Reels — Adeus Multa

## Especificações Técnicas

| Especificação    | Valor                                                    |
| ---------------- | -------------------------------------------------------- |
| Duração ideal    | 30-60 segundos                                           |
| Aspect ratio     | 9:16 (vertical)                                          |
| Resolução mínima | 1080x1920                                                |
| Legendas         | Obrigatórias (acessibilidade + som desligado)            |
| Música           | Royalty-free ou trending (até 15s para evitar copyright) |

## Hooks (Primeiros 2 Segundos)

### Fórmulas de Gancho

**Pergunta direta:**

- "Sabia que 70% das multas têm erro na notificação?"
- "Recebeu uma multa e não sabe o que fazer?"
- "Quanto tempo você tem pra recorrer de uma multa?"

**Afirmação impactante:**

- "Suspensão da CNH não é o fim da linha."
- "Multa por radar não é justa na maioria dos casos."
- "Você pode estar dirigindo irregular e nem sabe."

**Cenário específico:**

- "Você está no trânsito, é parado na blitz e..."
- "Imagina: você abre os Correios e encontra uma multa de R$ 800."
- "Seu chefe acabou de te mandar mensagem: 'onde está a defesa?'"

**Contraste:**

- "Todo mundo acha que recurso de multa é caro. E não é."
- "Advogado disse que não tem jeito. Será?"
- "Parece complicado, mas são 3 passos."

## Estrutura por Tipo

### Reel Educativo

```
[0-2s]   Gancho: pergunta ou dado surpreendente
[2-15s]  Problema: contextualiza a situação
[15-40s] Explicação: o que é, como funciona
[40-50s] Exemplo: aplicação prática
[50-60s] CTA: o que fazer agora
```

### Reel Mito ou Verdade

```
[0-2s]   Título: "Mito ou Verdade?"
[2-10s]  Afirmação polêmica
[10-30s] Explicação técnica
[30-45s] Veredito com fundamento
[45-60s] CTA
```

### Reel Alerta

```
[0-2s]   Gancho: "Atenção!" ou "Cuidado!"
[2-15s]  Problema: o erro ou armadilha comum
[15-40s] Consequência: o que pode acontecer
[40-50s] Solução: como evitar ou corrigir
[50-60s] CTA: ação preventiva
```

### Reel Pergunta & Resposta

```
[0-2s]   "Uma das perguntas que mais recebemos..."
[2-15s]  A pergunta (em destaque na tela)
[15-50s] Resposta completa
[50-60s] CTA para enviar mais perguntas
```

## CTAs para Reels

Consulte `cta-library.md` e escolha o CTA adequado ao objetivo do Reel.

Sempre incluir:

1. CTA verbal (falado)
2. CTA textual na tela (nos últimos 5 segundos)
3. CTA na legenda

## Erros Proibidos em Reels

- [ ] Gancho lento (mais de 3 segundos para prender)
- [ ] Sem legendas ou legendas pequenas
- [ ] Texto poluído na tela (mais de 2 linhas simultâneas)
- [ ] Tom de palestra ou aulas muito formais
- [ ] Promessas de resultado ("garantimos a anulação")
- [ ] Clickbait jurídico
- [ ] Informação sem fonte
- [ ] Música que abafa a voz
- [ ] Mais de um conceito por Reel
- [ ] Final sem CTA claro
