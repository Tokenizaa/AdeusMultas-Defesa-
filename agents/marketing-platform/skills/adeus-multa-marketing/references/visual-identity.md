# Identidade Visual — Adeus Multa

## Cores

### Primária

```css
primary: #1351B4
primary-hover: #0B3A8C
primary-light: #E8F0FE
```

Uso: Botões, links, headlines, elementos de destaque, logo.

### Sucesso

```css
success: #00a859;
```

Uso: Confirmações, checklists, indicadores positivos, CTAs de sucesso.

### Feedback

```css
danger:   #D93025  (erros, alertas críticos)
warning:  #F9AB00  (atenção, prazos)
info:     #1351B4  (informações)
```

Uso: Stories de alerta, prazos, mensagens de erro.

### Neutros

```css
text-primary:   #212121
text-secondary: #4A4A4A
muted:          #8A8A8A
border:         #D9D9D9
background:     #F5F5F5
white:          #FFFFFF
```

Uso: Corpo de texto, legendas, backgrounds, bordas.

### Gradiente (uso moderado)

```css
gradient: linear-gradient(135deg, #1351b4, #0b3a8c);
```

Uso: Capas de carrosséis, backgrounds de Stories, destaques visuais.

## Tipografia

### Fonte Principal

```
Inter
```

### Escala

```
12px — Caption / legendas
14px — Small / metadados
16px — Body / texto corrido
18px — Body large / destaque
20px — H3 / subtítulos
24px — H2 / seções
30px — H1 / títulos de post
36px — Display / capas, hero
```

### Pesos

```
400 — Regular (corpo)
500 — Medium (destaque leve)
600 — Semibold (subtítulos)
700 — Bold (títulos)
```

### Regras de Uso

- Corpo de texto: Inter 400, 16px
- Títulos grandes (capa): Inter 700, 36px
- Posts Instagram: Inter 600, 18-24px (depende da plataforma)
- Stories: Inter 700, 36-48px
- Carrosséis título: Inter 700, 30-36px
- Carrosséis corpo: Inter 400, 20-24px

## Estilo Visual

### Princípios

- **Limpo:** Sem poluição visual, espaços adequados
- **Confiável:** Cores sólidas, sem exageros
- **Acessível:** Alto contraste, fonte legível
- **Moderno:** Design atual, mas sem modismos
- **Consistente:** Mesmo padrão em todos os canais

### Backgrounds

- Posts: Fundo branco ou cinza claro (#F5F5F5)
- Stories: Cor sólida (primária) ou gradiente
- Carrosséis: Fundo limpo, sem texturas pesadas
- Capas: Gradiente, imagem com overlay ou cor sólida

### Imagens

- Fotos reais de trânsito, carros, estradas
- Imagens com filtro limpo (sem exageros)
- Tamanho consistente por formato
- Tratamento profissional, mas não genérico (evitar stock photos clichês)

### Elementos Gráficos

- Linhas e formas geométricas simples
- Cantos arredondados (border-radius: 8-12px)
- Sombras sutis quando necessário (box-shadow leve)
- Gráficos e infográficos no estilo da marca (cores primárias)

### Videos (Reels)

- Cortes rápidos e dinâmicos
- Legendas sempre presentes (acessibilidade)
- Cor de fundo clean com texto em destaque
- Texto grande e centralizado nos momentos de informação
- Música de fundo suave (não abafar a voz)

## Referências Visuais

### Inspiração de Estilo

- **Nubank:** Design limpo, acessível, amigável
- **Gov.br:** Seriedade, confiança, utilidade
- **Linear:** Minimalismo funcional, clareza
- **Stripe:** Profissionalismo moderno

### O que EVITAR

- Gradientes excessivos em todo o conteúdo
- Glassmorphism
- Animações pesadas ou lentas
- Múltiplos padrões visuais no mesmo conteúdo
- Fotos genéricas de banco de imagens sem contexto
- Fontes decorativas ou não-padrão
- Cores fluorescentes ou muito saturadas
- Layout poluído com muitos elementos
